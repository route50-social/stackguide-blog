Architecture

첫 서비스 배포, 인프라는 어디서 시작할까: AWS·Azure·오라클·네이버 클라우드·카페24 비교

처음 만든 서비스를 인터넷에 올릴 때 웹호스팅, 가상 서버, 관리형 앱 호스팅 중 무엇을 고를지 정리하고 AWS, Azure, 오라클 클라우드, 네이버 클라우드, 카페24의 무료 혜택·서버 요금·트래픽 요금을 2026년 11월 기준으로 비교합니다.

서비스를 처음 만들어 놓고 나면 바로 다음 질문이 생깁니다. “이걸 어디에 올려야 다른 사람도 접속할 수 있지?” 검색해 보면 AWS, Azure, 오라클 클라우드, 네이버 클라우드, 카페24가 한꺼번에 나오고, 어떤 글은 무료라고 하고 어떤 글은 요금 폭탄을 조심하라고 합니다.

결론부터 말하면 업체 이름보다 서비스를 어떤 방식으로 올릴지를 먼저 정해야 선택지가 확 줄어듭니다. 이 글에서는 세 가지 올리는 방식을 구분한 뒤, 다섯 업체의 무료 혜택과 서버·트래픽 요금을 같은 기준으로 놓고 비교합니다. 요금과 혜택은 모두 2026년 11월 11일에 각 업체의 공식 요금 페이지와 가격 API에서 확인한 값입니다.

먼저 정할 것: 어떤 방식으로 올릴 것인가

서비스를 인터넷에 올리는 방법은 크게 세 갈래입니다.

  • 웹호스팅(공유 호스팅): 업체가 운영하는 서버 한 대를 여러 고객이 나눠 씁니다. 웹 서버, PHP, MySQL 같은 환경이 이미 설치되어 있어서 파일만 올리면 됩니다. 값이 가장 싸고 손이 덜 가지만, 업체가 제공하는 언어와 버전 안에서만 움직일 수 있습니다.
  • 가상 서버(VPS·클라우드 VM): 나만 쓰는 가상의 컴퓨터 한 대를 빌립니다. 운영체제만 깔린 빈 서버를 받기 때문에 Node.js든 Python이든 원하는 것을 설치할 수 있습니다. 대신 설치, 보안 업데이트, 장애 대응을 직접 해야 합니다.
  • 관리형 앱 호스팅(PaaS): 코드를 올리면 업체가 서버와 런타임을 알아서 준비해 실행해 줍니다. 서버를 관리하지 않아도 되는 대신 요금 구조가 복잡해지기 쉽고, 플랫폼이 정한 방식에 맞춰야 합니다.

용어 풀이

  • VPS(Virtual Private Server, 가상 사설 서버): 물리 서버 한 대를 여러 개의 독립된 가상 서버로 나눠 그중 하나를 빌려주는 상품입니다. 국내 호스팅 업체에서 흔히 쓰는 이름입니다.
  • VM(Virtual Machine, 가상 머신): 소프트웨어로 만든 가상의 컴퓨터입니다. 클라우드 업체는 VM을 시간 단위로 빌려주며, AWS는 이를 인스턴스라고 부릅니다.
  • PaaS(Platform as a Service, 서비스형 플랫폼): 서버와 실행 환경을 업체가 관리하고, 사용자는 코드와 설정만 올리는 클라우드 서비스 방식입니다.
  • 런타임: 코드를 실제로 실행하는 환경입니다. 이 글에서는 Node.js, Python, Java처럼 서비스가 돌아가는 언어 실행 환경을 말합니다.

어떤 방식이든 하드웨어는 업체가 책임집니다. 차이는 그 위의 어디까지를 내가 맡느냐입니다.

그림 1. 호스팅 방식별로 직접 관리하는 범위 (일반적인 구분이며 상품마다 세부 범위는 다를 수 있음)

처음이라면 이렇게 생각하면 됩니다. 워드프레스나 PHP 게시판이면 웹호스팅으로 충분합니다. Node.js·Python·Java로 만든 서비스이거나 서버 다루는 법을 배우고 싶다면 가상 서버가 맞습니다. 서버 관리는 피하고 싶지만 웹호스팅으로는 안 되는 경우에 PaaS를 검토합니다. HTML·CSS·JavaScript만으로 된 정적 사이트라면 서버가 아예 필요 없으니 GitHub Pages 같은 정적 호스팅부터 보세요. 이 블로그도 그렇게 운영합니다.

다섯 업체는 어떤 곳인가

AWS: 선택지가 가장 많고, 그래서 처음엔 복잡하다

Amazon의 클라우드입니다. 서울 리전이 있고, 서버(EC2)부터 데이터베이스, 파일 저장소까지 거의 모든 것을 갖췄습니다. 자료와 사례가 많아 막혔을 때 답을 찾기 쉽다는 것이 실질적인 장점입니다.

용어 풀이

  • 리전(Region): 클라우드 업체가 데이터센터를 묶어 운영하는 지역 단위입니다. 사용자와 가까운 리전을 고를수록 응답이 빠르며, 같은 상품도 리전마다 요금이 다를 수 있습니다.
  • EC2(Elastic Compute Cloud): AWS의 가상 서버 서비스입니다. 사양별로 t3.small 같은 인스턴스 유형을 골라 시간 단위로 빌립니다.

단점은 같은 이유에서 나옵니다. EC2 서버 하나를 띄워도 디스크(EBS), 공인 IP, 트래픽이 각각 따로 청구되어 처음에는 한 달 요금을 짐작하기 어렵습니다. 그래서 입문자에게는 Lightsail이 자주 추천됩니다. 서버, SSD, 공인 IPv4, 일정량의 트래픽을 묶어 월 고정 요금으로 파는 상품이라 요금이 단순합니다.

용어 풀이

  • EBS(Elastic Block Store): EC2 서버에 붙이는 AWS의 디스크 서비스입니다. 서버 요금과 별도로 용량에 따라 청구됩니다.
  • 공인 IP: 인터넷에서 서버를 찾아올 수 있게 하는 공개 주소입니다. AWS와 Azure는 IPv4 공인 주소에 시간당 요금을 받습니다.

AWS의 PaaS로는 Elastic Beanstalk가 있으며, 이 서비스 자체에는 추가 요금이 없고 만들어지는 서버 등의 자원 요금만 냅니다. 한편 AWS App Runner는 2026년 4월 30일부터 신규 고객을 받지 않는다고 공식 페이지에 안내되어 있으니, 예전 글을 보고 App Runner로 시작하려 했다면 다른 방법을 찾아야 합니다.

Azure: 회사가 Microsoft 환경이라면 자연스러운 선택

Microsoft의 클라우드입니다. 한국 중부(Korea Central)와 한국 남부(Korea South) 리전이 있고, 회사에서 Microsoft 365나 Entra ID(옛 Azure AD) 계정을 쓰고 있다면 계정과 권한 관리를 그대로 이어 쓰기 좋습니다. .NET으로 개발한다면 도구 연동도 매끄럽습니다.

무료 계정 혜택과 관련해 주의할 점이 하나 있는데, 아래 “무료로 시작할 수 있는 범위”에서 따로 다룹니다.

PaaS인 App Service에는 무료(F1) 등급이 있습니다. 다만 공식 요금 페이지 기준으로 하루 CPU 사용 시간이 60분, 메모리 1GB, 저장 공간 1GB로 제한되고 SLA가 없으며 운영 서비스용이 아니라고 명시되어 있습니다. 연습용으로 보는 것이 맞습니다.

용어 풀이

  • SLA(Service Level Agreement, 서비스 수준 협약): 업체가 보장하는 가용성(예: 월 99.9%)과, 지키지 못했을 때의 보상을 정한 약속입니다.

오라클 클라우드(OCI): 무료 제공량이 가장 넉넉하지만 조건이 붙는다

오라클 클라우드는 기간 제한 없이 계속 무료인 Always Free 범위가 큽니다. 서울과 춘천 리전이 있습니다. 공식 문서 기준으로 Always Free에는 다음이 들어갑니다.

  • AMD 기반 소형 VM(VM.Standard.E2.1.Micro) 최대 2대, 각 1/8 OCPU·메모리 1GB
  • Arm 기반 Ampere A1 서버: 매달 1,500 OCPU시간과 9,000GB시간까지 무료. 문서는 이를 2 OCPU·메모리 12GB에 해당한다고 설명합니다.
  • 블록 스토리지 합계 200GB
  • 아웃바운드 데이터 전송 매달 10TB

용어 풀이

  • OCPU(Oracle CPU): 오라클 클라우드가 서버 CPU 성능을 세는 단위입니다. 다른 업체의 vCPU와 1:1로 대응하지 않으므로 사양을 비교할 때는 업체 문서를 따로 확인해야 합니다.
  • Arm: 스마트폰에서 널리 쓰이던 CPU 설계 방식으로, 최근에는 서버용으로도 많이 씁니다. AWS에서도 같은 메모리의 Arm 서버(t4g)가 Intel 서버(t3)보다 시간당 요금이 낮지만, 일부 프로그램은 Arm용 버전이 없을 수 있습니다.
  • 아웃바운드 트래픽: 서버에서 인터넷 쪽으로 나가는 데이터 양입니다. 방문자가 페이지나 이미지를 내려받을 때 생기며, 대부분의 클라우드는 들어오는 트래픽은 무료로, 나가는 트래픽은 유료로 받습니다.

오라클 가격 API에는 아직 A1 무료 구간이 3,000 OCPU시간·18,000GB시간으로 남아 있지만, 공식 문서와 무료 등급 안내가 모두 1,500·9,000으로 적고 있어 이 글은 후자를 따랐습니다.

조건도 분명히 알아 두어야 합니다. Always Free 서버는 가입할 때 정한 홈 리전에서만 만들 수 있고, A1은 춘천 리전에서는 만들 수 없다고 문서에 적혀 있습니다. 무료 서버가 모자라면 “out of host capacity” 오류가 나며, FAQ는 용량이 다시 생기기까지 며칠이 걸릴 수 있다고 안내합니다. 또 7일 동안 CPU 사용률(95번째 백분위수)이 20% 미만이고 네트워크 사용률도 20% 미만인 등 한가한 상태가 이어지면 오라클이 무료 서버를 회수할 수 있습니다. 가입에는 신용카드(또는 신용카드처럼 쓰이는 체크카드)가 필요하고, 선불·가상 카드는 받지 않습니다.

용어 풀이

  • 홈 리전: 오라클 클라우드 계정을 만들 때 고르는 기본 리전입니다. Always Free 자원은 이 리전에서만 만들 수 있으니 서울처럼 사용자와 가까운 곳을 고르는 것이 좋습니다.

네이버 클라우드: 원화 결제와 국내 지원이 필요할 때

국내 업체라 콘솔과 문서가 한국어이고 요금을 원화로 냅니다. 개인 계정으로도 가입할 수 있으며, 나중에 사업자등록증을 올려 사업자 계정으로 바꾸는 절차가 FAQ에 안내되어 있습니다.

입문자 기준으로 아쉬운 점은 서버 요금입니다. 현재 세대(3세대) 서버의 가장 작은 유료 사양이 2 vCPU·4GB(c2-g3)부터라서, 1~2GB짜리 작은 서버를 싸게 쓰는 선택지는 아래에서 설명할 Micro 서버 정도입니다. 표에 나온 서버 요금에는 디스크가 빠져 있고, 디스크와 공인 IP, 트래픽이 따로 붙습니다.

용어 풀이

  • vCPU(virtual CPU, 가상 CPU): 가상 서버에 배정되는 CPU 단위입니다. 업체와 서버 종류에 따라 vCPU 1개의 실제 성능은 다를 수 있습니다.

카페24: 가장 싸게, 가장 덜 신경 쓰고 시작하는 길

국내 호스팅 업체입니다. 월 몇천 원짜리 공유 웹호스팅이 대표 상품이고, 가상서버호스팅(VPS), 시간 단위로 쓰는 카페24 클라우드, Node.js·Python·Java 환경을 자동으로 설치해 주는 개발언어 VPS도 있습니다. 공유 웹호스팅과 가상서버호스팅 요금은 부가세 포함 가격으로 표시됩니다.

공유 웹호스팅은 PHP(8.4·8.2·7.4)와 MariaDB 환경이라 워드프레스나 PHP 게시판에 잘 맞습니다. 반면 같은 페이지의 공유형 node.js 호스팅은 Node.js v14·v12만 안내하고 있어 지금 새로 만드는 서비스에는 맞지 않습니다. 카페24도 Node.js·Python 사용자에게 VPS 상품을 권하고 있습니다. 확인 시점에 가상서버호스팅의 리눅스 상품에는 일시 품절 안내가 걸려 있었으니, 이 상품을 생각한다면 신청 가능 여부부터 확인하세요.

무료로 시작할 수 있는 범위

“무료”라는 말의 뜻이 업체마다 다릅니다. 기간 한정 크레딧인지, 기간 없이 계속 무료인 범위인지, 무료가 끝나면 자동으로 요금이 나가는지를 구분해서 봐야 합니다.

업체 신규 가입 혜택 계속 무료인 범위 무료가 끝나면
AWS 가입 시 $100 크레딧, 지정된 활동(EC2 실행, 예산 설정 등)을 하면 최대 $100 추가 30개 이상 서비스의 월별 무료 사용량 무료 플랜은 6개월 또는 크레딧 소진 시 종료, 유료 전환하지 않으면 계정이 닫히고 90일 뒤 데이터 삭제
Azure 30일 동안 쓰는 $200 크레딧, 12개월 무료 서비스 65개 이상 상시 무료 서비스 종량제로 전환하지 않으면 계정과 서비스가 비활성화
오라클 최대 30일 동안 쓰는 US$300 체험 크레딧(일부 국가) Always Free(위 목록) 유료 자원은 회수, Always Free 자원은 유지
네이버 클라우드 결제 수단 등록 후 10만 원 할인 크레딧(3개월), Micro 서버 1년 무료 — Micro 서버는 반납하지 않으면 1년 뒤 자동 과금
카페24 이번에 확인한 상품 페이지에는 무료 제공 상품 없음 — —

용어 풀이

  • 프리 티어(Free Tier): 클라우드 업체가 신규 고객이나 소량 사용자에게 일정량을 무료로 주는 제도입니다. 업체마다 기간, 대상 서비스, 한도가 다릅니다.
  • 크레딧: 요금 대신 쓸 수 있는 금액입니다. 유효 기간이 지나거나 다 쓰면 사라집니다.

표만으로는 드러나지 않는 함정이 몇 가지 있습니다.

AWS 크레딧의 유효 기간은 공식 문서끼리도 표현이 엇갈립니다. FAQ의 한 문장은 무료 크레딧이 계정 생성 6개월 뒤 만료된다고 하고, 같은 FAQ의 다른 문장과 EBS 요금 페이지는 계정 생성 12개월 안에 써야 한다고 적습니다. 어느 쪽이든 AWS의 새 무료 제도는 2025년 7월 15일 이후 가입한 계정에 적용되며, 무료 플랜 기간(최대 6개월)이 끝나기 전에 유료로 전환할지 정해 두는 것이 안전합니다. 무료 플랜에서는 요금이 청구되지 않지만, 유료 플랜으로 바꾼 뒤에는 크레딧을 넘는 사용량에 정상 요금이 붙습니다.

Azure의 12개월 무료 VM은 고를 크기를 확인하세요. 무료 계정 안내에는 B1s, B2pts v2(Arm), B2ats v2(AMD) VM을 각각 월 750시간 무료로 준다고 되어 있습니다. 그런데 Microsoft Learn의 VM 크기 지원 종료 문서에는 B1s를 포함한 B 시리즈 v1이 지원 종료 단계에 들어갔고, 2026년 7월부터 새 구독에서는 이 크기를 만들 수 없다고 적혀 있습니다. 지금 새로 가입한다면 B2ats v2를 고르는 것이 안전합니다.

네이버 클라우드 Micro 서버는 서버 요금만 무료입니다. 1 vCPU·메모리 1GB·디스크 10GB(mi1-g3) 사양이고, 계정당 1대, 국내 거주자만, 리눅스만 쓸 수 있습니다. 공인 IP, 네트워크 트래픽, 10GB를 넘는 디스크는 따로 청구되며, 기본 디스크를 10GB보다 늘리면 처음 10GB까지 포함한 전체 용량에 요금이 붙습니다. 1년이 지나면 월 10,850원(부가세 별도)이 자동으로 청구되고, 업체는 한 달 전에 메일·문자로 알려 준다고 안내합니다.

비슷한 사양의 서버를 한 달 켜 두면

메모리 2~4GB 정도의 작은 서버를 한 달 내내 켜 둔다고 보고 공개 요금을 나란히 놓았습니다. 클라우드는 시간 단위 요금이 기본이라, 시간 요금만 공개된 상품은 한 달을 730시간으로 잡아 직접 계산했습니다. 통화와 부가세 기준이 업체마다 달라 환율로 바꾸지 않고 원래 단위 그대로 적었습니다. AWS·Azure·오라클 요금은 세금 별도 미국 달러 기준입니다.

용어 풀이

  • NVMe(Non-Volatile Memory Express): SSD를 빠르게 연결하는 방식입니다. 상품 설명에 NVMe가 있으면 일반 SSD보다 디스크 읽기·쓰기가 빠른 편입니다.
  • 버스터블 인스턴스: 평소에는 정해진 기준 CPU 사용률(예: 20%)만 쓰다가, 아껴 둔 여유분으로 잠깐 더 높은 성능을 내는 저가형 서버입니다. AWS의 t3·t4g, Azure의 B 시리즈가 여기에 해당하며, 계속 CPU를 많이 쓰는 서비스에는 맞지 않습니다.

표에서 가장 먼저 눈여겨볼 것은 “별도” 칸입니다. AWS EC2의 t4g.small 서버 요금은 약 $15이지만, 공인 IPv4 요금 약 $3.65에 디스크와 트래픽 요금이 더해집니다. 반대로 Lightsail은 이 셋을 묶어 $12로 고정했기 때문에 처음 쓰는 사람이 예산을 잡기 쉽습니다. 네이버 클라우드 c2-g3도 서버 요금에 디스크가 빠져 있어서, 50GB 디스크를 붙여 한 달(730시간) 쓰면 디스크만 약 5,840원, 공인 IP가 약 4,088원 더해집니다(필자 계산, 부가세 별도).

사양 숫자만 보고 고르지 않는 것도 중요합니다. 카페24 가상서버호스팅 표에는 vCPU 수가 나와 있지 않고, 오라클의 OCPU와 다른 업체의 vCPU는 단위가 다릅니다. 같은 “2코어”라도 성능이 같다고 볼 수 없습니다.

놓치기 쉬운 트래픽 요금

서버 요금은 매달 거의 같지만 트래픽 요금은 방문자 수에 따라 달라집니다. 이미지나 동영상이 많은 서비스라면 서버보다 트래픽이 더 나올 수도 있습니다.

업체 무료 또는 포함량 초과 요금 (첫 구간)
AWS (서울) 매달 100GB (모든 서비스·리전 합산) GB당 $0.126 (10TB까지)
AWS Lightsail 플랜에 포함 (2GB 플랜 월 3TB) 서울 리전 초과 단가는 확인하지 못함
Azure (Korea Central) 매달 100GB GB당 $0.12 (기본 Microsoft 네트워크 경로)
오라클 (아시아·태평양) 매달 10TB GB당 $0.025
네이버 클라우드 매달 20GB GB당 100원 (5TB까지, 부가세 별도)
카페24 클라우드 사용 시간 × 1.4GB (한 달 켜 두면 약 1TB) GB당 150원부터 (부가세 별도)
카페24 가상서버호스팅 플랜별 월 포함량 (비즈니스 500GB) GB당 165원, 다음 달 정산

예를 들어 한 달에 300GB를 내보내는 서비스라면, AWS EC2에서는 무료 100GB를 뺀 200GB × $0.126 = 약 $25.2, 네이버 클라우드에서는 280GB × 100원 = 28,000원(부가세 별도)이 트래픽 요금으로 나옵니다. 같은 양이 Lightsail 2GB 플랜이나 오라클에서는 포함량 안이라 추가 요금이 없습니다. AWS의 무료 100GB는 계정 전체에서 합산되므로, 다른 서비스도 함께 쓰면 그만큼 줄어든다는 점도 기억해 두세요.

상황별로 고르는 법

지금까지의 내용을 질문 순서로 정리하면 다음과 같습니다.

그림 2. 첫 배포 인프라를 고르는 질문 순서 (이 글의 비교를 바탕으로 한 필자의 정리)

  • 워드프레스나 PHP 게시판: 카페24 공유 웹호스팅이 가장 싸고 간단합니다. 하루 트래픽 한도가 있으니 방문자가 늘면 상위 상품이나 가상 서버로 옮길 계획을 세워 두세요.
  • 돈을 들이지 않고 서버를 배워 보고 싶다: 오라클 Always Free가 가장 넉넉합니다. 다만 무료 서버를 못 만들거나 회수될 수 있으니 운영 서비스보다는 학습용으로 생각하는 편이 맞습니다. 6개월 동안 AWS 무료 플랜으로 배우는 것도 방법이며, 배운 내용을 그대로 실무에 쓰기 좋습니다.
  • Node.js·Python 서비스를 매달 같은 요금으로 운영하고 싶다: AWS Lightsail이나 카페24 개발언어 VPS처럼 서버·IP·트래픽을 묶은 상품이 예산 관리에 유리합니다.
  • 원화 결제와 한국어 콘솔·문서가 중요하다: 네이버 클라우드가 맞습니다. 서버 요금 외에 디스크·공인 IP·트래픽을 더해 예산을 잡으세요.
  • 회사가 이미 Microsoft 계정과 도구를 쓴다: Azure로 시작하면 계정 관리와 결제를 한곳에서 할 수 있습니다.

어느 쪽을 고르든 처음 고른 곳에 영원히 묶이는 것은 아닙니다. 서비스를 Docker 컨테이너처럼 다른 서버로 옮기기 쉬운 형태로 만들어 두면, 작은 곳에서 시작했다가 트래픽이 늘었을 때 옮기는 부담이 줄어듭니다.

용어 풀이

  • 컨테이너(Docker): 프로그램과 실행에 필요한 라이브러리·설정을 한 묶음으로 포장해 어느 서버에서나 같은 방식으로 실행하게 하는 기술입니다. Docker는 컨테이너를 만들고 실행하는 대표 도구입니다.

처음 배포할 때 미리 해 둘 것

  • 예산 알림부터 설정하세요. AWS는 AWS Budgets로 예상 요금이 정해 둔 금액을 넘으면 메일을 보내도록 할 수 있고, 이 설정은 AWS 무료 크레딧을 추가로 받는 활동 목록에도 들어 있습니다. 다른 업체도 콘솔에서 요금 알림을 먼저 찾아 켜 두는 것이 좋습니다.
  • 연습용 자원은 끝나면 삭제하세요. 서버를 “중지”해도 디스크와 고정 공인 IP 요금은 계속 나갈 수 있습니다. 실습이 끝났다면 서버, 디스크, IP를 모두 지웠는지 확인합니다. 삭제한 자원은 되돌릴 수 없으니 필요한 데이터는 먼저 백업하세요.
  • 무료 기간이 끝나는 날을 달력에 적어 두세요. AWS 무료 플랜은 최대 6개월, Azure 크레딧은 30일, 네이버 클라우드 Micro 서버는 1년입니다. 끝나는 방식(계정 닫힘, 비활성화, 자동 과금)도 업체마다 다릅니다.
  • 요금은 다시 확인하세요. 이 글의 숫자는 2026년 11월 11일 기준이며 클라우드 요금과 무료 혜택은 자주 바뀝니다. 실제로 신청하기 전에 각 업체의 요금 계산기나 요금 페이지에서 원하는 리전과 사양으로 다시 확인하세요.

기준과 한계

  • 요금은 2026-11-11에 공식 요금 페이지와 가격 API(AWS Price List API, Azure Retail Prices API, Oracle Price List API)에서 확인했습니다. 리전은 AWS 서울(ap-northeast-2), Azure Korea Central, 네이버 클라우드 한국 리전 기준입니다. 오라클 가격 API는 트래픽을 빼면 리전별 가격을 따로 주지 않습니다.
  • 730시간 환산과 트래픽 예시는 필자가 계산했습니다. 실제 청구액은 업체의 월 계산 방식(일할 계산, 744시간 기준 등), 세금, 할인, 환율에 따라 달라집니다.
  • 오라클의 공인 IP 요금 여부, OCPU와 vCPU의 대응 관계, Lightsail의 서울 리전 초과 트래픽 단가, 카페24 가상서버호스팅의 vCPU 수는 확인하지 못했습니다.
  • 각 업체의 서버를 직접 만들어 성능을 측정하지는 않았습니다. 이 글의 비교는 공개된 요금과 조건을 기준으로 합니다.
