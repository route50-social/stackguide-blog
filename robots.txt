# 검색 엔진·AI 수집 규칙
# 모든 검색 엔진과 AI 검색·학습용 수집기가 사이트 전체를 수집할 수 있도록 허용하고, sitemap 위치를 알려 줍니다.
# StackGuide는 공개 글이 AI 검색의 답변 근거와 AI 모델 학습에 쓰이는 것을 허용합니다.
# 공개 주소를 바꾸면 아래 Sitemap 주소와 llms.txt 안내도 함께 수정합니다.

# 일반 검색 엔진 (Googlebot, Bingbot, Yeti(네이버), Daumoa(다음) 등)
User-agent: *
Allow: /

# AI 검색·학습용 수집기. 위의 전체 허용과 같은 규칙이지만, 허용 의도를 분명히 하려고 따로 적습니다.
# 특정 수집기를 막으려면 그 이름만 이 묶음에서 빼고 "Disallow: /" 묶음을 따로 만듭니다.
# 이름과 용도는 각 회사의 공식 문서에서 확인했습니다(2026-11-13).
# - OpenAI: GPTBot(학습), OAI-SearchBot(ChatGPT 검색), ChatGPT-User(사용자 요청)
# - Anthropic: ClaudeBot(학습), Claude-SearchBot(검색), Claude-User(사용자 요청)
# - Google: Google-Extended(Gemini 학습·응답 근거 사용 허용 표시, Google 검색 색인과는 별개), Google-CloudVertexBot(Vertex AI 에이전트)
# - Apple: Applebot(Siri·Spotlight 검색), Applebot-Extended(Apple 생성형 AI 학습 사용 허용 표시)
# - Perplexity: PerplexityBot(검색), Perplexity-User(사용자 요청)
# - Meta: meta-externalagent(AI 학습·색인), meta-webindexer(Meta AI 검색)
# - Amazon: Amazonbot(서비스 개선·AI 학습), Amzn-SearchBot(Alexa 검색)
# - DuckDuckGo: DuckAssistBot(AI 답변)
# - Mistral: MistralAI-Index(검색), MistralAI-Training(학습), MistralAI-User(사용자 요청)
# - CCBot: Common Crawl (여러 AI 학습 데이터의 공개 원천)
